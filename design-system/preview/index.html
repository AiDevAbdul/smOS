Every chart goes through ChartCard, which owns these four states plus the “Show table” fallback — so no chart can ship without an empty state or a screen-reader equivalent. Card height is reserved by the wrapper, so async data cannot shift layout.
12 — Chart palette (aliases of the semantic tokens, so a theme flip repaints every plot)
--ds-chart-1…7 are aliases: blue, green, amber, red, teal, purple, steel. Order mirrors CHART_PALETTE in scripts/lib/design_system.py so the report and Console sides cannot drift. Charts resolve them at draw time via getComputedStyle (useChartTheme) and re-resolve on smos:theme-change — never baked-in hex. Flip the theme above and watch these swatches move.
